# Code of conduct

Casement follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in issues, discussions, pull requests and anywhere else you speak for the project. Please read it before taking part.

## Reporting

To report behaviour privately, open the **...** menu on the comment, issue or pull request, choose **Report content**, then **Report to repository admins**. If the problem isn't tied to one comment, open an issue asking the maintainer to get in touch, and leave the details out of it.

The maintainer reviews every report, keeps the reporter's identity private, and acts along the lines of the Covenant's enforcement guidelines.
