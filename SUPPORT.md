# Getting help

Islet is free, and help is given on GitHub on a best-effort basis. There's no email or paid support, and replies can take a while.

## Where to ask

- **Questions, ideas and setup help:** [Discussions](https://github.com/aviralgarg05/islet/discussions).
- **Bugs and feature requests:** [open an issue](https://github.com/aviralgarg05/islet/issues/new/choose) with one of the forms. Search the existing issues first.
- **Security problems:** please don't open an issue. See [SECURITY.md](SECURITY.md).

The docs answer a lot already: [Live Activities](docs/LIVE-ACTIVITIES.md), [Integrations](docs/INTEGRATIONS.md), [AI](docs/AI.md), the [API](docs/API.md) and [Shortcuts](docs/SHORTCUTS.md).

## What to include

- the Islet version (*Settings → About*, or `isletctl health`);
- the macOS version (Apple menu → *About This Mac*);
- the Mac model, and whether its display has a notch;
- which displays were connected, and which one the island was on;
- the settings involved, or the relevant part of `~/.config/islet/config.json`;
- for a Live Activity problem, the output of `isletctl debug menubar`, run while the activity shows in the menu bar;
- a screenshot or screen recording for anything visual.

Before you post, remove anything personal: names, addresses, messages, scores, tokens and keys. Debug output and screenshots can hold all of these.
